# Fila Fácil

Protótipo didático de emissão e chamada de senhas em ordem FIFO.

## Origem

Projeto desenvolvido a partir do Lab 02 da disciplina TEC.1053 — Tópicos Especiais em Programação — IFPI.

Repositório original: <https://github.com/aislanifpi/tec1053>

## Funcionalidades

- emissão sequencial de senhas;
- atendimento por ordem de chegada (FIFO);
- exibição da fila de espera;
- contabilização de chamadas;
- aviso quando a fila está vazia;
- reinício da demonstração mediante confirmação.

## Limitações

- uma fila independente por aba;
- estado armazenado apenas em memória;
- recarregar a página inicia uma nova sessão;
- sem backend;
- sem banco de dados;
- sem persistência;
- sem sincronização;
- sem dados pessoais reais.
