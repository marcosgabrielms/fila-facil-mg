# Lab 02 — Fila Fácil

Aplicam-se também as regras da raiz. Este laboratório usa HTML, CSS e JavaScript
nativos; a convenção Python da raiz não se aplica aos arquivos deste lab.

Leia ESPECIFICACAO.md antes de editar. No exercício básico, implemente somente os
corpos de emitirSenha, chamarProxima e reiniciarFila em src/fila.js. Preserve os
nomes, o objeto global FilaFacil, o formato do estado e as funções já fornecidas.
Não altere tests/, a especificação, a interface fornecida, o Lab 01 ou dependências.
Não adicione framework, API, armazenamento persistente, prioridade ou autenticação.

Faça um incremento por vez. Não capture exceções para esconder falhas nem retorne
resultados específicos dos testes. Aplique as regras a qualquer sequência válida.
As entradas das operações são estados válidos criados por criarEstado; validação
de objetos arbitrários está fora do contrato.

Os testes deste lab são JavaScript e rodam em tests/index.html, no navegador.
Se Node já estiver disponível, a mesma suíte pode ser executada da raiz com:

    node labs/lab-02-fila-facil/tests/executar.mjs

Não use pytest como evidência do Lab 02: ele só coleta os testes Python do Lab 01.
Se não tiver navegador controlável nem Node, informe que a execução depende do aluno;
não afirme que os testes passaram. Registre pedidos em prompts/ e saídas em evidencias/.

Não leia credenciais. Não compre serviços nem publique a aplicação. Use somente
senhas numéricas fictícias, sem dados de pacientes. As extensões em EXERCICIOS.md
são uma etapa posterior, mediante orientação do professor.
